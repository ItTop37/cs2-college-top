# CS2 COLLEGE TOP

1. В Google Таблице назовите лист `Заявки`. Заголовки A–K: Дата, Команда, Игрок 1, Игрок 2, Игрок 3, Игрок 4, Игрок 5, Запасной 1, Запасной 2, Статус, ID заявки.
2. В Google Apps Script замените Code.gs содержимым файла `Code.gs`.
3. Развернуть → Управление развертываниями → Редактировать → Новая версия → Развернуть. Выполнять от имени меня, доступ всем.
4. На GitHub Pages загрузите index.html, style.css, script.js. Файл Code.gs загружать на сайт не нужно.
5. Проверьте тестовую заявку в таблице.

Публичный Apps Script может подвергаться спаму; перед массовым запуском нужна защита. Таблицу с ФИО не публикуйте.
