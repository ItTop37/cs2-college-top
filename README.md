# CS2 COLLEGE TOP — обновление карточки колледжа

Загрузите на GitHub Pages: `index.html`, `style.css`, `script.js`, `favicon.svg`, `images/logo.png`.

**Важно:** `Code.gs` на GitHub Pages не выполняется. Если заявка записывается без ID в K, откройте Google Таблицу → Расширения → Apps Script, вставьте актуальный `Code.gs` и выполните **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**. Не создавайте новое развертывание. В таблице заголовок K1 = `ID заявки`.

Для диагностики откройте адрес веб-приложения с параметрами `?action=status&requestId=fd8382a8-1157-4268-a556-d60d1454486a`. Если ответ `{"ok":false}` или Google показывает ошибку, проверьте развертывание и журналы Apps Script. Старые заявки, записанные прежним кодом, не получат ID автоматически.
